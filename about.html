How Artvue works

Artvue is a demonstration gallery. The artists are invented. The prices are there so the catalogue can be read the way a real one is read. You cannot pay here.

Look

Use the catalogue. Category, style, medium, price, size, and orientation all narrow the same floor. The address bar keeps the edit you made, so a link can be sent as-is.

Read the lot line

Each work carries a title, an artist, a medium, a size, a year, and a price in US dollars. A sold work stays visible, marked, so the wall does not pretend it is still free.

Inquire

Buy / Inquire on WhatsApp opens a message that already names the piece, the artist, the size, the price, and this page. A person replies. There is no cart.

Commission, if you need a specific wall

Request a commission starts a separate note. Say the room and the scale. The studio side of that conversation is also fictional in this demo.
